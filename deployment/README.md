# Deployment Documentation

This directory contains information regarding the deployment setup and environment configurations for the AI Chatbot application.

## 🚀 Setup Instructions
* **Prerequisites**: Python 3.10+, pip
* **Environment Variables**: Create a `.env` file in the root directory and add necessary API keys.
* **Local Run**: 
  ```bash
  pip install -r requirements.txt
  python app.py
  ```
.
